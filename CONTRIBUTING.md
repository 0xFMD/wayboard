# Contributing

## Guidelines

1. Fork the repo
2. Build and run by following [Getting Started](docs/getting-started.md).

3. Create a new branch for your change:

   ```bash
   git checkout -b feature/your-feature
   ```

### PRs

- One change for each PR and explain what changed and why
- Better to add screenshot or video for visual changes
- Format your code before committing

  ```bash
  clang-format -i src/*.cpp includes/*.hpp
  ```

### Reporting Bugs

- Open issue and explain what you expected and what happened
- Your distro and QT version
- Whether you ran wayboard nested or bare metal
